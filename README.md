# 팀 실시간 위치 공유

같은 소속팀 대원끼리만 서로의 위치를 실시간으로 보는 지도. 서버가 없는 정적 사이트이고,
위치 정보는 기기에서 암호화되어 오간다. 배경 지도는 **네이버 지도**를 쓴다.

**접속 주소** https://forestgps.github.io/team-location-share/

<img src="qr/team-location-share-qr.png" alt="접속 주소 QR 코드" width="220" />

휴대폰 카메라로 위 QR을 스캔하면 바로 접속됩니다. 대원들에게 배포할 때는
[`qr/team-location-share-qr.png`](qr/team-location-share-qr.png) 파일을 보내거나,
인쇄용으로는 해상도 손실이 없는 [`qr/team-location-share-qr.svg`](qr/team-location-share-qr.svg)를 쓰세요.
브라우저에서 QR을 띄워 보여 주려면 [초대 페이지](https://forestgps.github.io/team-location-share/invite.html)를 열면 됩니다.

QR에는 접속 주소만 들어 있습니다. 팀 암호는 담기지 않으니 별도로 전달해야 합니다.

## 지도 API 키 (필수 설정)

배경 지도는 네이버 지도 JS API v3 다. `index.html` 의 스크립트 태그에 **Client ID** 가
`ncpKeyId` 로 들어 있다. 이 값은 브라우저에 그대로 노출되는 공개 값이므로 감출 필요가 없다.
네이버는 키를 숨기는 방식이 아니라 **등록된 주소에서만 동작하게 하는 방식**으로 보호한다.

그래서 네이버 클라우드 플랫폼 콘솔에서 이 사이트 주소를 등록해야 한다. 등록하지 않으면
인증 요청이 401 로 거부되고 지도가 빈 화면으로 남는다.

1. [네이버 클라우드 플랫폼 콘솔](https://console.ncloud.com/) → Services → AI·NAVER API →
   Application → 해당 애플리케이션 → 변경
2. **Web 서비스 URL** 에 아래를 등록한다

   | 주소 | 용도 |
   | --- | --- |
   | `https://forestgps.github.io` | 실제 배포 주소 |
   | `http://localhost:8080` | `serve.ps1` 로컬 개발 서버 |

3. 저장하고 몇 분 기다린 뒤 사이트를 새로고침한다

**Client Secret 은 이 저장소에 넣지 않는다.** 정적 사이트에 두면 그대로 공개되고, JS API 는
Secret 을 쓰지 않는다. Secret 은 서버에서 부르는 API(정적 지도, 지오코딩 등)에만 쓰이므로
이 프로젝트에는 필요가 없다. 실수로 노출했다면 콘솔에서 즉시 재발급해야 한다.

지도가 안 뜨면 화면에 안내 상자가 나타난다. 그때는 위 등록 목록부터 확인하면 된다. 지도가
없어도 메시지·메모 목록·임무 기록은 계속 쓸 수 있게 되어 있다.

## 지도 유형과 등고선

지도 왼쪽 위에서 배경 지도를 바꿀 수 있다. 고른 유형은 기기에 기억되어 다음 접속에도 유지된다.

| 유형 | 내용 |
| --- | --- |
| 일반 | 네이버 기본 지도 |
| 지형 | 네이버 지형도. 음영기복과 봉우리 표고점이 나온다 |
| 등고선 | OpenTopoMap. 실제 등고선과 표고 라벨이 나온다 |
| 위성 | 네이버 위성 사진 |

**등고선은 네이버가 제공하지 않는다.** 네이버 지형도 타일을 직접 받아 확인해 보면 음영기복과
봉우리 표고점만 있고 등고선 자체가 없다. 그래서 등고선 유형만 OpenTopoMap 타일을 쓴다.
네이버 지도 API 의 `ImageMapType` 으로 붙였기 때문에 마커·경로·메모는 유형을 바꿔도 그대로다.

OpenTopoMap 은 무료 공개 타일이라 저작자 표시가 이용 조건이고, 지도 아래에 자동으로 표시된다.
확대는 17단계까지만 된다(OpenTopoMap 이 제공하는 상한). 그보다 더 확대해야 하면 일반이나
위성으로 바꾼다.

## 대원 고도

각 대원 마커의 이름표 위에 현재 고도가 미터 단위로 표시된다. 팀원 목록에도 고도와 수직 오차가
같이 나온다.

고도는 GPS 가 잡혀야 나온다. 실내나 와이파이 측위 상태에서는 값이 없고, 그때는 고도 표시가
생략된다. 위치가 갱신될 때마다 같이 갱신되며, 반올림한 값이 바뀔 때만 마커를 다시 그린다.

한 가지 유의할 점이 있다. **기기가 주는 고도는 WGS84 타원체 기준이라 해수면 기준 표고와 다르다.**
한반도에서는 대략 20~25m 정도 높게 나온다. 대원끼리의 고도차나 오르내림 추세를 보는 데는
문제가 없지만, 지도에 적힌 봉우리 표고와는 그만큼 차이가 난다. 정확한 표고가 필요하면 등고선
지도의 값을 기준으로 삼는 것이 낫다.

## 사용법

1. 위 주소로 접속한다.
2. **소속팀 이름**과 **팀 암호**를 입력한다. 팀원 전원이 동일하게 입력해야 서로가 보인다.
3. 위치 권한을 허용한다.

팀 암호는 팀장이 정해서 대원들에게 별도 경로(구두, 보안 메신저 등)로 전달한다. 링크나 QR에는
담기지 않는다. 휴대폰에서 브라우저 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 설치된다.

## 임무와 메모

**임무 시작 / 임무 종료** 버튼은 지도 화면 오른쪽 위에 있다. 한 명이 시작을 누르면 팀 전체가
동시에 기록을 시작하고, 각 대원의 이동 경로가 서로 겹치지 않는 색으로 그려진다. 종료를 누르면
임무 날짜, 시작·종료 시각, 소요 시간, 참여 대원, 이동 거리가 담긴 저장 창이 뜬다. 저장 창은
**종료를 누른 대원의 기기에만** 뜬다. 다른 대원은 누가 종료했는지 알림만 받고 기록이 정리된다.
저장한 임무는 **기록** 버튼에서 다시 열어 지도에 겹쳐 보거나 파일로 내려받을 수 있다.

저장 창의 선택지는 셋이다.

1. **MP4로 변환하여 저장** — 기록을 저장한 뒤 이동 경로가 시간순으로 그려지는 1280×720 영상을
   만들어 기기에 저장한다. 지도 배경 위에 대원별 색 경로와 이름표, 하단에 임무명·시각·이동
   거리·범례가 들어간다.
2. **MP4 변환 안 하고 저장** — 기록만 바로 저장한다. 기다릴 필요가 없다.
3. **저장 안 함** — 이번 기록을 버린다.

저장한 임무를 GeoJSON 파일로 받으려면 **기록** 버튼에서 해당 임무의 내려받기를 누른다.

영상은 서버 없이 기기에서 만든다. 캔버스에 경로를 실제 속도로 재생하면서 `MediaRecorder` 로
녹화하는 방식이라 재생 길이(약 22초)만큼 실제로 기다려야 하고, **그동안 이 화면을 켜 둔 채로
두어야 한다.** 다른 앱으로 넘어가거나 화면을 끄면 브라우저가 화면 갱신을 멈춰 영상이 끊긴다.
진행률은 저장 창에 표시된다.

영상의 배경 지도만은 OpenStreetMap 타일을 쓴다. 화면 지도는 네이버지만, 네이버는 타일을 직접
받아 캔버스에 그려 넣을 수 있는 공개 경로를 제공하지 않는다. 정적 지도 API 는 Client Secret 을
서버에서 붙여야 하므로 서버 없는 이 사이트에서는 쓸 수 없다. 그래서 영상 배경은 OSM 으로 두고
저작자 표시를 영상 안에 넣는다.

MP4 컨테이너를 지원하지 않는 브라우저(파이어폭스 등)에서는 자동으로 WebM 으로 떨어지고 버튼
문구도 그렇게 바뀐다. 녹화 자체가 불가능한 브라우저에서는 영상 선택지가 숨겨진다. 영상 만들기가
실패해도 기록은 먼저 저장되므로 유실되지 않고, 실패 원인이 저장 창 안에 표시된다.

### 파일이 저장되는 곳

브라우저로 접속한 경우에는 보통의 내려받기 폴더에 들어간다.

안드로이드 앱에서는 사정이 다르다. WebView 는 다운로드를 스스로 처리하지 않아서, 웹에서 만든
파일을 그냥 내려받게 하면 **아무 일도 일어나지 않는다.** 그래서 앱에서는 웹이 파일을 512KB
조각으로 잘라 네이티브로 넘기고, 앱이 그것을 **다운로드 폴더**에 직접 써 준다. 저장이 끝나면
파일 이름과 크기가 토스트로 뜬다. 안드로이드 10 이상은 `MediaStore` 를 쓰므로 저장 권한이
필요 없고, 9 이하에서만 저장 권한을 한 번 묻는다.

자동 저장이 막힌 환경에서는 저장 창에 파일 링크가 나타난다. 그것을 직접 눌러 저장하면 된다.
만들어 둔 영상은 버리지 않는다.

**메모** 버튼은 지도 왼쪽 위에 있다. 누른 뒤 지도를 터치하면 그 지점에 핀이 꽂히고, 메모 본문과
사진·동영상을 첨부할 수 있다. 핀을 누르면 위도·경도(십진수와 도분초), **군사좌표(MGRS)**, UTM
좌표가 표시되고 좌표를 한 번에 복사할 수 있다.

메모의 좌표와 본문은 팀원에게 암호화되어 즉시 공유된다. 사진과 동영상은 팀원이 그 메모를 열어 볼
때 요청이 가고, 그 파일을 가진 대원의 기기가 24KB 조각으로 잘라 암호화해 보내면 받는 쪽에서 다시
합친다. 작성자만 응답하는 구조가 아니라 먼저 받은 대원이 중계할 수 있어서, 작성자가 접속을 끊어도
파일을 가진 대원이 한 명이라도 있으면 계속 퍼진다. 여러 명이 동시에 보내 채널을 낭비하지 않도록
짧게 무작위로 기다린 뒤 이미 누군가 보내고 있으면 양보한다. 사진은 전송 속도를 위해
긴 변 1600px, JPEG 품질 0.75로 자동 축소된다. 동영상은 브라우저에서 재인코딩할 수 없어 원본으로
보내므로 용량이 크면 시간이 걸린다(대략 5MB에 15초 안팎).

받은 첨부는 각자 기기의 IndexedDB에 저장되어 이후에는 작성자 없이도 볼 수 있다. 임무 기록은
localStorage에 저장된다. 어느 쪽도 서버나 브로커에 남지 않는다.

군사좌표 변환은 표준 UTM 투영식과 MGRS 100km 방격 규칙을 직접 구현했고, 미국 측지청(NOAA NCAT)
변환 결과와 대조해 검증했다. 위도 84°N 이상, 80°S 이하 극지방은 UPS 좌표계를 쓰므로 지원하지 않는다.

## 팀 메시지

상단 **메시지** 버튼을 누르면 접속 중인 같은 팀 대원 전원에게 글을 보낼 수 있다. 위치와 같은
암호화 채널을 쓰므로 브로커도 내용을 볼 수 없고, 서버에 저장되지 않는다. 최근 200건만 각자
기기에 보관된다. 엔터로 보내고 Shift+엔터로 줄을 바꾼다.

메시지가 오면 진동과 경고음이 울리고, 창을 닫아둔 상태면 버튼에 안 읽은 개수가 표시된다.
경고음은 음원 파일 없이 브라우저가 즉석에서 만들어 내므로 통신이 나쁜 곳에서도 확실히 울린다.

**알람** 버튼으로 진동·소리를 켜고 끌 수 있다. 설정은 기기에 저장되어 다음 접속에도 유지된다.
끄면 화면 표시로만 알린다.

### 앱을 보고 있지 않을 때

안드로이드 앱은 입장하는 순간 메시지 수신 서비스를 켠다. 그래서 다른 앱을 쓰고 있거나 화면이
꺼져 있어도 메시지가 오면 **화면 위에 팝업 알림**이 소리·진동과 함께 뜬다. 이 서비스는 위치
권한과 무관하게 동작하며, 위치 추적은 **화면 꺼짐 추적** 버튼으로 따로 켠다. 알림 표시줄에
현재 어느 모드로 돌고 있는지 계속 표시된다.

진동은 네이티브로 직접 울린다. 브라우저의 진동 API는 기기와 정책에 따라 조용히 무시되는 경우가
많아서, 앱에서는 그 경로를 쓰지 않는다.

브라우저로 접속한 경우에는 알림 권한을 허용하면 다른 탭을 보고 있을 때 시스템 팝업이 뜬다.
다만 브라우저를 완전히 닫거나 화면을 끄면 메시지를 받지 못한다. 브라우저 엔진의 제약이므로
현장에서는 앱으로 쓰는 것을 권한다.

## 안드로이드 앱

`android/` 폴더에 앱 프로젝트가 있다. 화면은 이 사이트를 그대로 띄우고, 위치 추적만 네이티브
포그라운드 서비스로 따로 돌린다. 그래서 **화면이 꺼져도 팀에 위치가 계속 전달된다**. 브라우저나
PWA로는 이게 불가능하다. 화면이 꺼지면 브라우저 엔진이 위치 갱신을 멈추기 때문이다.

네이티브 서비스는 웹과 똑같은 방식(PBKDF2 20만 회 → AES-GCM)으로 암호화하고 같은 토픽에
같은 대원 id 로 발행한다. 그래서 팀원 지도에서는 화면을 켜든 끄든 끊김 없이 이어진다. 팀 이름과
암호는 메모리에만 두고 저장하지 않는다.

앱에 들어가면 상단에 **화면 꺼짐 추적** 버튼이 생긴다. 처음 켤 때 위치 권한을 "항상 허용"으로
요청하니 승인해야 한다. 켜져 있는 동안에는 알림이 계속 떠 있고, 알림의 중지 버튼으로도 끌 수 있다.

### APK 만들기

아무도 JDK나 안드로이드 SDK를 설치할 필요가 없다. GitHub Actions가 대신 빌드한다.

- 저장소 Actions 탭 → Android APK → Run workflow → 결과는 Artifacts에서 내려받는다
- `v1.0.0` 처럼 태그를 붙여 push하면 서명된 APK가 Releases에 자동 올라간다

### 서명 키 등록 (업데이트를 계속 배포하려면 필수)

안드로이드는 **같은 키로 서명된 APK만 같은 앱의 업데이트로 인정한다.** 서명 키를 등록하지 않으면
디버그 서명 APK가 나오는데, 그 키는 빌드마다 달라져서 다음 버전을 설치할 때 "앱이 설치되지
않았습니다" 오류가 난다. 실제 운용에서는 아래 절차를 한 번 해두어야 한다.

1. Actions 탭 → **서명 키 만들기** → Run workflow
2. 끝나면 Artifacts의 `signing-key`를 내려받는다 (zip 안에 키와 암호, 지문이 들어 있다)
3. Settings → Secrets and variables → Actions 에 4개를 등록한다

   | 이름 | 값 |
   | --- | --- |
   | `KEYSTORE_BASE64` | `keystore.base64.txt` 내용 전체 |
   | `KEYSTORE_PASSWORD` | `password.txt` 내용 |
   | `KEY_ALIAS` | `teamloc` |
   | `KEY_PASSWORD` | `password.txt` 내용 (위와 같은 값) |

4. 내려받은 zip을 안전한 곳에 보관한다. **잃어버리면 앱 업데이트를 낼 수 없다.**
5. Android APK 워크플로를 다시 돌리면 서명된 APK가 나온다

암호는 워크플로가 무작위로 만들고 로그에 남기지 않는다. 결과 파일에만 들어 있다. 등록을 마치면
Artifacts는 삭제하고 개인 보관본만 남긴다. 키와 암호를 아는 사람은 누구나 업데이트를 낼 수 있다.

서명 키의 SHA-256 지문은 `.well-known/assetlinks.json`에 들어 있다. 이 파일이 있어야 앱에서
사이트 링크를 열 때 브라우저 선택 창이 뜨지 않는다. **서명 키를 새로 만들면 이 파일의 지문도
같이 바꿔야 한다.** JDK가 설치된 환경이라면 `android\make-assetlinks.ps1`로 로컬에서 키와
이 파일을 만들 수도 있다.

## 팀 전용 브로커

기본값은 공개 MQTT 브로커다. 첨부 보관 기간과 용량을 팀이 직접 정하려면
[`broker/README.md`](broker/README.md)를 따라 팀 브로커를 붙이면 된다.
접속 화면 고급 설정에 주소와 아이디·암호를 넣거나, 초대 페이지에서 그 설정을
QR에 담아 대원들에게 한 번에 넘길 수 있다.

안드로이드는 이 파일을 **도메인 루트에서만** 찾는다. 즉
`https://forestgps.github.io/.well-known/assetlinks.json` 이어야 하고, 이 저장소의 하위 경로에
있는 사본은 참고용이다. 실제로 서비스되는 파일은 별도 저장소
[`forestgps/forestgps.github.io`](https://github.com/forestgps/forestgps.github.io)에 있다.
지문을 바꿀 때는 두 곳을 함께 고쳐야 한다.

### 어떤 수정에 APK를 다시 만들어야 하나

화면 내용, 지도, 메모, 임무 같은 웹 부분을 고치는 것은 APK와 무관하다. 웹 파일을 고쳐 push하면
모든 대원 앱에 1분 안에 반영된다. APK를 다시 빌드해야 하는 것은 앱 이름, 아이콘, 권한,
백그라운드 서비스, 파일 저장처럼 네이티브 부분을 바꿀 때뿐이다.

> **1.3.0 은 APK 재빌드가 필요하다.** 파일 저장이 네이티브 기능이라 웹만 갱신해서는 앱에서
> 임무 영상이 저장되지 않는다. 대원들이 1.2.0 을 쓰고 있으면 저장 창에 파일 링크만 뜬다.
> Actions 탭에서 Android APK 워크플로를 돌려 새 APK를 배포해야 한다.

## 보안 모델

팀 이름과 팀 암호에서 PBKDF2-SHA256(20만 회)으로 512비트를 유도해 절반은 AES-GCM 암호화 키로,
절반은 MQTT 토픽 이름으로 쓴다. 결과적으로

- 위치 좌표는 AES-GCM으로 암호화되어 전송된다. 브로커 운영자도 내용을 볼 수 없다.
- 토픽 이름 자체가 암호에서 유도되므로, 팀 암호를 모르면 팀 채널의 존재조차 알 수 없다.
- 팀 이름이나 암호가 다르면 토픽이 달라 메시지가 전달되지 않고, 우연히 토픽이 겹쳐도
  복호화에 실패해 무시된다.
- 팀 이름과 암호는 평문으로 네트워크에 나가지 않는다.

한계도 분명히 해둔다. 같은 팀 암호를 가진 사람끼리는 서로를 신뢰한다고 가정하므로 팀 내부
스푸핑은 막지 않는다. 암호가 유출되면 팀 전체가 새 암호로 교체해야 한다. 기본 브로커는 공개
브로커(EMQX, HiveMQ, Mosquitto를 순서대로 시도)라 내용은 안전하지만 가용성은 보장되지 않는다.
가용성까지 보장하려면 입장 화면의 고급 설정에 자체 MQTT 브로커 주소를 넣는다.

## 수정하는 방법

### 휴대폰이나 외부 PC에서 (설치 불필요)

저장소 페이지에서 `.` 키를 누르면 브라우저에서 VS Code가 열린다. 또는 주소창의 `github.com`을
`github.dev`로 바꿔도 된다.

```
https://github.dev/forestgps/team-location-share
```

파일을 고치고 왼쪽 Source Control 탭에서 커밋하면 GitHub Pages가 자동으로 다시 빌드한다.
1분 안에 접속 주소에 반영된다.

### 이 PC에서

```powershell
cd c:\team-location-share
powershell -ExecutionPolicy Bypass -File .\sync.ps1
```

변경사항을 모두 커밋하고 푸시한 뒤, Pages 빌드가 끝날 때까지 기다리며 결과를 알려준다.
커밋 메시지를 지정하려면 `-Message "설명"`을 붙인다.

로컬에서 먼저 확인하고 싶으면 개발 서버를 띄운다. 위치 권한은 HTTPS나 localhost에서만 나오므로
`index.html`을 파일로 직접 열면 동작하지 않는다.

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 입장 화면과 지도 화면 |
| `app.js` | 위치 추적, MQTT 송수신, 마커·경로·메모 UI |
| `naver-map.js` | 네이버 지도 API 감싸개 (지도 조작을 여기로 모아 둠) |
| `crypto-team.js` | 키 유도와 페이로드 암복호화 |
| `palette.js` | 대원별 색상 중복 없는 배분 |
| `mission.js` | 임무 경로 기록과 저장·내보내기 |
| `route-video.js` | 임무 경로를 mp4 영상으로 렌더링 (기기 내 처리) |
| `android/.../MainActivity.java` | 웹 화면 담기, 권한 중개, 파일을 다운로드 폴더에 저장 |
| `mgrs.js` | 위경도 → UTM → 군사좌표(MGRS) 변환 |
| `memo.js` | 메모와 첨부 파일 저장 (IndexedDB) |
| `media.js` | 사진 축소, 첨부 조각 전송·조립 |
| `chat.js` | 팀 메시지 저장과 검증 |
| `alert.js` | 진동·경고음과 알람 켜기/끄기 |
| `styles.css` | 화면 스타일 |
| `manifest.json`, `sw.js`, `icons/` | PWA 설치와 앱 셸 캐시 |
| `serve.ps1` | 로컬 개발 서버 (localhost 전용) |
| `sync.ps1` | 커밋·푸시·배포 확인 |
| `share.ps1`, `invite.html` | GitHub이 막힌 환경에서 이 PC를 임시 공개 서버로 쓰는 경로 |

## 임시 터널 (예비 수단)

GitHub Pages를 쓸 수 없는 상황에서는 이 PC를 임시 공개 HTTPS 서버로 노출할 수 있다.

```powershell
powershell -ExecutionPolicy Bypass -File .\share.ps1
```

Cloudflare 임시 터널로 주소를 만들고 QR 초대 페이지를 띄운다. 실행 중에는 주소를 아는
누구나 접근할 수 있고, Ctrl+C로 종료하면 주소도 사라진다. 상시 운용에는 Pages 주소를 쓴다.
